# Biomarcadores-en-la-Amiloidosis-AL-

Este repositorio contiene todo el material complementario del Trabajo de Fin de Máster titulado: "Biomarcadores noveles de la Amiloidosis de Cadenas Ligeras (AL): una *scoping review*. Esto incluye toda la documentación y código generado para la realización del trabajo, así como los resultados obtenidos. 

## Descripción del Proyecto
El objetivo de esta *scoping review* es mapear e identificar **biomarcadores noveles** reportados en la literatura científica durante los últimos 10 años para mejorar el diagnóstico y la estratificación del riesgo en pacientes con amiloidosis AL. Esta revisión sigue el modelo para revisiones sistméticas, en concreto para *scoping reviews* descrito en la declaración **PRISMA 2020** (PRISMA-ScR). Se llevó a cabo un enfoque metodológico por fases: 
- Búsqueda y filtrado inicial.
- *Screening* automático de títulos y abstracts y *screening* manual para la selección de estudios.
- *Screening* de textos completos para la extracción de datos, incluyendo la generación de tablas y figuras como resumen de la información.
